# Sample Dashboard

I built this Google Sheets dashboard to compare competitor pricing across products, plan tiers, and billing units. I also designed a reusable review workflow to keep the benchmark current as vendors change their pricing.

**[View the sample dashboard (Nov 26, 2026)](https://docs.google.com/spreadsheets/d/15208kfswgQp7cq5RDeSg0H9LfT8nIYURunnKdPYGnog/edit?usp=sharing)**

## What to explore

- **Summary** shows pay-as-you-go pricing across competing products.
- **Company Details** records plan tiers, billing units, and links to vendor pricing sources.
- **Calculator** lets you compare pricing at different usage levels where billing units are comparable.

The review workflow checks listed prices against their vendor sources, flags entries it can’t verify, and creates a dated copy so changes can be reviewed over time.
